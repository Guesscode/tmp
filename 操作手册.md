Mac：
- 把你需要转移的文件拖动到tmp目录内

- 打开终端，输入 cd Desktop/tmp ，按回车
示例：
heyuyang@MacBook-Air-654 ~ % cd Desktop/tmp 
heyuyang@MacBook-Air-654 tmp % 

- 输入git add . (是git add 英文句号) ，按回车
- 输入git commit -m "（内容随便，不重要）" ，按回车
示例：
[main 990f75b] 4

on your username and hostname. Please check that they are accurate.

    git config --global user.name "Your Name"
    git config --global user.email you@example.com

After doing this, you may fix the identity used for this commit with:

    git commit --amend --reset-author

ThinkPad：
- 在桌面打开tmp文件夹，在搜索框中输入cmd，按回车， 会看见出现黑框
- 输入git pull， 观察文件变化

注意：配置文件的有效期是七天，起始时间是11月7日23点58分， 截止于11月14日23点58分
